# 체력 연동 전투 보상 및 아웃게임 강화 비용 기획안

- 작성일: 2026-11-14
- 상태: 검토용 기획안. 기획툴·게임 코드·서버 차트 미적용.
- 범위: 일반 전투 종료 골드·강화석 보상, 일반 유닛 계정 강화 비용, 현재 BASIC 영구강화 비용.
- 검증 범위: 수학 모델의 수입·지출 및 구매 시점 확인. 실제 Unity 전투·서버 지급 검증은 미실행.

## 1. 목표와 전제

하루 3판의 일반 전투 보상만으로, 한 유닛에 강화석을 집중 투자하여 약 6개월에 만렙에 도달하도록 설계한다.

- 6개월은 180일, 총 540판으로 계산한다.
- 이벤트·출석·미션·광고·우편·구매·최초 달성 보상·초기 지급은 계산에서 제외한다.
- 하루 3판은 성장 기간 계산 기준이며 일일 보상 제한이 아니다.
- 계정 골드는 영구강화, 강화석은 일반 유닛 계정 강화에 사용하는 안이다.
- 전투 중 식량의 소환·생산·강화 경제는 이 문서의 범위에 포함하지 않는다.
- 일반 유닛 만렙은 현재 기준인 Lv20을 사용한다. 족장에는 일반 유닛 가격표를 자동 적용하지 않는다.
- 영구강화 전체 완료도 기준 모델에서 540판으로 잡았다. 이는 이번 기획의 추가 가정이며, 사용자 조건인 유닛 만렙 6개월과 별도로 조정할 수 있다.

## 2. 체력 기반 보상

라운드 구간별 고정 단가를 사용하지 않고 실제로 등장한 보스의 최대 체력으로 보상을 계산한다.

이 문서에서 보상 기준이 되는 체력은 **보스 등장 시 최대 체력**이다. 남은 체력은 마지막 보스의 공략 진행률을 산출하는 데 사용한다.

### 2.1 기획 변수

| 변수 | 값 또는 정의 |
|---|---|
| 기준 체력 | 해당 난이도의 첫 일반 보스 최대 체력 |
| 기본 골드 | 60 |
| 기본 강화석 | 6 |
| 체력 보상 지수 | 0.2 |
| 체력 기준 시점 | 보스 등장 시 확정된 최대 체력 |
| 피해 진행률 | 등장 최대 체력 대비 전투 중 최고 HP 감소 비율 |

기준 체력과 보스 등장 최대 체력은 해당 전투에서 확정된 값을 사용한다.

### 2.2 보스별 계산식

```text
체력 비율 = 해당 보스의 등장 최대 체력 / 기준 체력
체력 계수 = 체력 비율 ^ 0.2

피해 진행률 = clamp(
    (등장 최대 체력 - 전투 중 최저 체력) / 등장 최대 체력,
    0,
    1
)

보스별 골드   = 60 * 체력 계수 * 피해 진행률
보스별 강화석 =  6 * 체력 계수 * 피해 진행률
```

- 처치한 보스의 피해 진행률은 1이다.
- 마지막 미처치 보스도 실제 공략한 비율만큼 보상에 포함한다.
- 보스가 회복해도 전투 중 최고 HP 감소 비율까지만 인정한다. 같은 체력을 반복해서 깎아 추가 보상을 얻지 않는다.
- 오버킬로 피해 진행률이 1을 넘지 않는다.
- 일반·어려운 보스의 체력 차이는 이 계산에 자연스럽게 반영된다. 별도의 라운드별 고정 보상표는 두지 않는다.

### 2.3 체력 보상 지수의 의미

지수가 1이면 체력에 정확히 정비례한다. 이번 권장값 0.2는 후반 보상 증가를 완만하게 만드는 값이다.

체력이 복리로 증가하는 게임에서 보상까지 체력에 정비례시키면 후반 재화 수입도 급격히 커진다. 체력 성장률이 13%일 때 지수 0.2를 적용하면, 동일 역할 보스의 보상 증가율은 성장 1회당 약 2.47%다.

```text
보상 증가 배율 = 1.13 ^ 0.2 ≈ 1.02474
```

| 기준 대비 보스 체력 | 단독 처치 시 골드 | 단독 처치 시 강화석 |
|---:|---:|---:|
| 1배 | 60 | 6 |
| 2배 | 68 | 6 |
| 4배 | 79 | 7 |
| 10배 | 95 | 9 |
| 40배 | 125 | 12 |
| 400배 | 198 | 19 |

표는 해당 보스 한 마리만 정산하고 소수점을 내린 예시다. 실제 한 판에서는 보스별 계산값의 소수점을 유지한 채 모두 합산한다.

정수 재화이므로 표시값이 같을 수 있지만 내부 계산값은 체력에 따라 계속 증가한다. 특정 라운드 경계에서 단가를 인위적으로 바꾸지 않는다.

## 3. 전투 종료 정산

### 3.1 소수점과 연구 보너스

보스별 계산 도중에는 소수점을 버리지 않는다. 한 판의 보상을 모두 더하고, 해당 재화의 전투 획득 증가 효과를 적용한 다음 재화별로 한 번 내린다.

```text
최종 골드 = floor(
    보스별 골드 합계 * (1 + 전투 골드 획득 증가율)
)

최종 강화석 = floor(
    보스별 강화석 합계 * (1 + 전투 강화석 획득 증가율)
)
```

기본 지급분은 이 최종 정수량으로 확정한다. 소수 부분은 이번 전투의 기본 지급에 포함하지 않는다.

현재 게임의 전투 연구 보너스 지급 API에는 별도의 소수 나머지 이월 처리가 있다. 위 식을 실제 적용할 때는 **최종 내림과 이월 정책을 한 경로로 맞춰야 한다.** 기존 API를 호출하는 것만으로 이 기획과 동일한 정산이 된다고 가정하지 않는다.

### 3.2 부분 공략 예시

기준 체력의 4배인 보스를 절반까지 공략했다면 다음 값이 전투 보상 합계에 추가된다.

```text
골드   = 60 * 4^0.2 * 0.5 ≈ 39.58
강화석 =  6 * 4^0.2 * 0.5 ≈  3.96
```

이 단계에서 39골드·3강화석으로 자르지 않는다. 앞서 공략한 보스들의 보상과 합산한 뒤 최종적으로 내린다.

### 3.3 지급과 결과 표시

- 시간 초과로 정상 종료해도 그 전투에서 얻은 보상을 지급한다.
- 정상 전투 결과 정산에 연결한다. 튜토리얼·테스트·중도 포기·오류 종료는 정상 종료와 구분한다.
- 결과 화면은 정산이 끝난 최종 골드·최종 강화석을 그대로 표시한다.
- 동일 전투의 정산 재시도는 같은 실행 ID를 사용하여 중복 지급하지 않는다.
- 계정 경험치와 전투 중 식량은 이 재화 공식에 합치지 않는다.

### 5.3 비용 생성식

목표 레벨을 L, k=L−1로 놓는다. `round10(x)`는 10개 단위 반올림이다.

```text
A = 122.83401441574097
p = 1.831298828125

k <= 14:
    필요 강화석 = round10(A * k^p)

k > 14:
    필요 강화석 = round10(A * 14^p * (1 + 0.03 * (k - 14)))
```

Lv16 이후에는 계정 특수 보너스를 새로 가정하지 않았으며, 상대적인 기본 스탯 증가도 작아지므로 가격 증가 폭을 낮췄다.

보유 유닛의 계정 강화 비용만 포함한다. 유닛 해금·최초 구매 비용은 포함하지 않는다. 강화석을 다른 유닛에 분산하면 목표 유닛의 만렙 시점은 늦어진다.

## 6. 영구강화 비용

### 6.1 적용 대상

현재 BASIC 트리의 **21개 노드·총 99회 강화**를 기준으로 한다. 노드 ID·부모 조건·효과·최대 레벨은 유지하며 비용 재화만 골드로 부여하는 안이다.

보류 중인 30단계·57노드·210회 강화 준비본은 이 비용표에 섞지 않는다. 해당 트리를 적용한다면 별도의 비용 재산정이 필요하다.

### 6.2 비용 공식

행번호 Row는 0부터 시작한다. `round50(x)`는 50골드 단위 반올림이다.

```text
q = 1.6145706176757812

반올림 전 첫 비용 = 200 * q^Row * 효과 가중치
첫 강화 비용 B = max(50, round50(반올림 전 첫 비용))
단계당 증가 S = max(50, round50(반올림 전 첫 비용 * 0.25))

다음 강화 비용 = B + S * 현재 노드 레벨
```

직접 전투 효과의 가중치는 해당 노드를 한 번 강화했을 때의 기대 DPS 증가율을 기준 증가율 0.2%로 나눈 뒤 0.5~3배로 제한한다.

```text
효과 가중치 = clamp(1회 강화 기대 DPS 증가율 / 0.002, 0.5, 3)
```

식량 생산·시작 식량·토템 효과는 실제 편성 의존성이 커서 가중치 1을 임시 사용한다. 직접 DPS와 동등한 가치라고 확정한 것은 아니다.

### 6.3 비용 예시와 총량

| 노드 예시 | 첫 비용 | 단계당 증가 | 마지막 단계 비용 |
|---|---:|---:|---:|
| 첫 공격력 노드 1-1 | 200 | 50 | 300 |
| 중간 스킬 쿨타임 노드 6-1 | 1,100 | 250 | 2,100 |
| 중간 스킬 피해 노드 6-2 | 2,200 | 550 | 4,400 |
| 마지막 공격력 노드 12-1 | 38,850 | 9,700 | 116,450 |

전체 비용은 **1,684,450골드**다. 골드를 전부 연구에 사용하는 기준 모델에서는 540판에 전체 연구를 완료한다.

다른 골드 소비처를 추가하면 그 지출 예산을 먼저 제외하고 연구 완료 기간을 다시 계산한다. 전체 연구 완료 후의 지속적인 골드 소비처는 이 기획에 추가하지 않는다.

## 7. 기획툴 및 게임 적용 범위

이 문서는 설계를 보관하는 단계이며 아래 항목은 아직 구현·반영하지 않았다.

| 대상 | 반영할 내용 |
|---|---|
| 전투 재화 설정 | 기본 골드 60, 기본 강화석 6, 기준 체력, 체력 보상 지수 0.2 |
| 유닛 강화 비용 | 일반 유닛의 목표 레벨별 강화석 비용표 |
| BASIC 영구강화 | 노드별 비용 재화 Gold, 첫 비용, 단계당 증가 비용 |
| 전투 결과 정산 | 실제 보스 체력·최고 피해 진행률로 최종 골드·강화석 계산 |
| 결과 화면 | 확정된 최종 골드·최종 강화석 표시 |

현재 연구는 무료이며, 기획툴 배포 경로에서도 연구 비용 필드를 제외하고 있다. 비용표만 입력해도 게임의 골드 차감이 연결되는 구조는 아니므로 실제 적용 시 배포·파싱·구매·저장 경로를 함께 연결해야 한다.

기존 계정 진행을 초기화하거나 과거 강화에 비용을 소급 청구하는 내용은 포함하지 않는다.

## 8. 계산 가정과 검증 경계

### 8.1 체력 및 진행 가정

판당 보상 예시와 성장 기간 계산은 다음 가정을 사용했다.

- 일반 보스 체력: 기준 체력 × 1.13^(라운드−1).
- 어려운 보스 위치: 10라운드 주기의 3·6·10번째.
- 어려운 보스 체력: 해당 라운드 일반 보스 체력 × 1.10 × 1.13^2.
- 집중 투자 유닛의 덱 전력 기여율: 50%.
- 계정 강화 기본 스탯 배율: 1 + 0.1 × (계정 레벨−1).
- 숙련 증가: 장기적으로 15%, 시상수 60판.
- 연구 DPS 근사: 치확 30%·치피 200%, 일반공격/시간충전 스킬 피해 비중 50:50.


각 판에서 보상 수입 → 유닛 강화 구매 → 부모 조건을 만족하는 연구 구매 → 다음 판의 진행 상승을 순서대로 계산했다. 연구 구매는 싼 노드 우선의 기준 정책을 사용했다.
