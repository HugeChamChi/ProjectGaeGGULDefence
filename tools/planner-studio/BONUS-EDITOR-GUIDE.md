# 보너스 능력·알팡 설명 편집

2026-10-30. 현재 구현 범위: 유닛 능력 표 + 유닛/알팡 설명·강조·기존 팝업 링크. 알팡의 신규 실제 능력을 구현하거나 강화 구매를 서버 구매로 바꾸지는 않는다.

## 편집

1. 강화 밸런스 → 유닛 → **보너스 능력**: 대상, 해금 레벨, 순번, 능력 종류, 스탯, 단위, 수치를 선택한다. 퍼센트 5는 5%다. 같은 레벨에 효과를 여러 개 넣으려면 순번 0,1로 나눈다.
2. **보너스 설명·알팡 링크**: 대상과 해금 레벨별 설명을 입력한다. 설명이 없는 유닛은 능력 수치에서 자동 문구를 만든다.
3. 숫자 강조와 용어 링크 체크박스를 설정한다. 설명 아래 미리보기로 색과 문구를 확인한다.
4. 설명의 `[해킹]`, `[자폭드론]`, `[액티브 스킬]`은 기존 게임 용어 팝업으로 연결한다. 알팡에는 `{공격속도효과}`를 넣고 특수 효과 링크를 **알팡 공격속도 효과**로 선택한다. 이 링크는 기존 툴팁을 재사용한다. 툴팁의 지속시간/수치 자체는 이번 편집 항목이 아니다.
5. 실제 효과는 보너스 능력 표가 결정한다. 설명을 수정하는 것만으로 피해량이나 효과가 바뀌지는 않는다. 알팡 설명 5개는 기존 화면 문구를 가져온 것이며 신규 능력 실행 보증이 아니다.

## Excel / 뒤끝

- 작성용: `BonusEffect`, `BonusDescription` 두 시트. 기획툴로 다시 가져와 편집 가능하다.
- DEV 적용 → **유닛 보너스·알팡 설명** → Base64 OFF → 적용 파일 준비.
- 업로드용: 단일 `UnitLevelBonuses` 시트, `RecordType=Part`(능력)와 `Description`(문구) 행. 일반 열 형식이며 JSON/Base64/ReleaseKey 셀은 없다.
- 기존 차트 **DEV_UnitLevelBonuses**에 업로드 후 파일 적용. 기존 45행 효과 전용 파일도 게임은 계속 읽을 수 있다.
- 다른 차트는 이번 설명 변경 때문에 다시 올릴 필요 없다.
- 게임 Play를 재시작한 뒤 보너스 탭에서 확인한다. 정의는 앱 실행 중 고정되므로 서버 파일 변경만으로 이미 열린 화면이 자동 갱신되지는 않는다.

## 테스트 범위

- 효과 45개 + 베탕·알팡 설명 10개의 툴 스키마·Excel 왕복·기존 프로젝트 이관·태그 거부 검사.
- 실제 Electron 편집 탭 렌더링 및 기존 화면 smoke 검사.
- Unity의 효과/설명 행 분리, 알팡 토큰·강조 설정 복원 및 임의 TMP 태그 거부 검사.
- 새 설명 포함 파일의 서버 다운로드와 실제 게임 링크 터치는 업로드 적용 후 검증해야 한다.
