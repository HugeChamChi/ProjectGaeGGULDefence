# 레벨 보너스 편집

강화 밸런스 → 유닛 → 레벨 보너스 설계에서 유닛과 해금 레벨을 선택한다. 효과 추가 버튼으로 독립 효과를 여러 행 연결한다. 숫자는 한글 입력란에서 수정하고 설명 토큰 버튼으로 설명에 연결한다. 미리보기는 실제 수치를 사용한다.

효과 한 행의 Value는 효과별 고정 순서다. 예: 해킹 후 공속 강화 `15,2` = 공속 15%, 2초. 베탕 주기 강화 `2,40,0` = 2번째, 피해 40%, 충전 감소 0%. 등급별 값은 노말·레어·에픽·전설 순서다. Name·UnitName·PartIndex는 직접 관리하지 않는다.

작성용 엑셀은 BonusDefinition/BonusEffect 두 시트로 다시 가져올 수 있다. DEV 적용의 유닛 보너스에서 내보낸 `.backend.xlsx`만 DEV_UnitLevelBonuses 차트에 업로드하고 파일 적용한다. 다른 차트는 다시 올릴 필요 없다.

Unity 메뉴 `Tools > Backend Tests > 보너스 Value 규약 검사`를 열어 업로드용 엑셀을 선택한다. 대상 유닛과 레벨을 바꾸어 해금·설명·누적 수치를 확인한다. 베탕은 자폭 1회 완료 버튼으로 주기 강화도 검사한다. 엑셀을 수정하면 다시 불러온다. 로컬 검사이며 서버·계정은 변경하지 않는다. 서버 적용 확인은 새 차트 적용 후 Play를 재시작한다.
