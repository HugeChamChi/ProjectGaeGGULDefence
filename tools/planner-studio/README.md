# GGD 기획 작업실 콘텐츠 확장

**적용 전 확인:** [실무 적용 판단 및 적용 순서](APPLICATION-AUDIT.md). 전체 데이터의 운영 연결은 미완료입니다. 아래 과거 설명보다 이 적용 범위와 TEAM-GUIDE.md를 우선 확인하세요.

**뒤끝 DEV 적용** 메뉴: 미션 설정과 유닛 기본 스탯 파일 준비 → 공식 콘솔 업로드·적용 → Unity 연결을 통한 서버 파일 대조를 제공합니다. 유닛 기본 스탯의 화면·전투 연결을 추가했고 원본 SO는 유지합니다. 자동 업로드 API, 계정 강화 구매, 미션 저장·지급은 구현되지 않았습니다. 자세한 준비 조건은 [팀 사용 안내](TEAM-GUIDE.md)를 확인하세요.

개발 담당자는 [유지보수 안내](MAINTENANCE.md)에서 모듈 책임·공통 통신·검증 진입점을 확인할 수 있습니다.

**팀 전달은 [팀 사용 안내](TEAM-GUIDE.md)를 기준으로 합니다.** 현재는 편집·내보내기용 검증 버전이며, 실제 운영 이벤트 지급은 미지원입니다. 설정 창에서 기능별 게임 적용 범위를 확인할 수 있습니다. `release-team.py --output <새ZIP경로>`는 실행 런타임·원본 동봉 자료·팀 안내와 해시 목록을 묶으며 개인 작업 자료와 임시 백업을 제외합니다.

강화 트리에 게임용 `IconAddress` 필드를 추가했다. 기존 `IconKey`는 툴 미리보기다. [강화 차트 작업·사용법](../backnd-mcp/RESEARCH-CHART.md)에 ResearchBalance.xlsx 내보내기, Addressables 등록, 게임 적용 순서를 정리했다. 기존 사용자 파일은 덮어쓰지 않는다.

**이벤트 → 데이터 연결 / 미션 이벤트**를 추가했습니다. 코드에서 제공한 실행 지점별로 데이터를 연결하고 목표·기간·보상을 편집합니다. `MissionEvents.xlsx`에 비활성 3주 예시가 있습니다. [설정과 게임 연결 범위](EVENT-DATA.md)를 확인하세요. 미션 진행은 현재 세션 내 계산까지 연결되어 있으며 뒤끝 저장·재접속 복원·보상 지급은 미연결입니다.

출석은 **이벤트 → 출석 이벤트**입니다. `AttendanceEvent.xlsx`는 이벤트 설정/일차별 보상을 `EventKey`로 연결하며, `AttendanceEventExample.xlsx`는 기간을 채운 **비활성 7일 예시**입니다. [이벤트 구조와 예시](ATTENDANCE-EVENT.md)를 확인하세요. 기존 Attendance.xlsx는 백업 후 이관했습니다.

유닛 자료는 **UnitBalance.xlsx 하나의 Units / BaseStats / UpgradeStats / LevelBonuses 시트**로 통합했습니다. UnitKey에서 BaseStatKey·UpgradeKey·LevelBonusKey를 참조합니다. 기본 스탯은 실제 등급별 값을 포함하고 강화는 레벨당 증가량으로 저장합니다. 예전 UnitLevelBonus.xlsx는 백업으로 이동했습니다. 상세 규약은 [EXCEL-CONTRACT.md](EXCEL-CONTRACT.md)를 확인하세요.

프로젝트 안에서 실행: **[기획작업실 실행.cmd](기획작업실%20실행.cmd)** 또는 `Tools/planner-studio/GGD-Planner/GGD-Planner.exe`.

실행 파일·런타임·자료와 개발 소스를 모두 이 폴더 안에 보관합니다. 실행·재빌드에 Downloads 폴더가 필요하지 않습니다. 실행 파일을 전달할 때는 `GGD-Planner` 폴더 전체를 전달하세요. 기존 개인 작업은 동일한 사용자 저장 폴더를 사용합니다.

Git에는 `app/` 소스·의존성 잠금 파일·동봉 Excel·검증/패키징 스크립트를 포함합니다. `GGD-Planner/` 실행 배포본, node_modules, 백업과 검증 출력은 제외합니다. 새 PC에서는 `npm.cmd ci --prefix tools/planner-studio/app --ignore-scripts`로 의존성을 설치하고, 실행/패키징에는 별도 전달받은 기존 `GGD-Planner` 런타임을 사용하세요. 카탈로그 생성/패키징에는 .NET 9 SDK도 필요합니다.

기존 밸런스 편집 옆에 **강화 밸런스**, **출석**, **기본 설정**을 배치했습니다. 별도 보상 탭은 없습니다. 기존 개발 소스가 이 체크아웃에 없어 배포본 `resources/app.asar`에서 소스를 추출했습니다. `original-app.asar`는 수정 전 원본입니다.

## 기획자 사용법

왼쪽 **설정 → 다크 모드**의 **ON / OFF** 스위치로 화면 테마를 변경합니다. 콘텐츠 편집 화면에도 함께 적용되며, 선택은 이 PC에 저장되어 다음 실행에도 유지됩니다.

1. **강화 밸런스** → **유닛 / 영구강화**. 유닛의 **유닛 정보**에서는 한 유닛의 기본 정보·덱 해금·레벨별 비용/성장·보너스 해금 레벨을 함께 확인하고 **수정 → 수정 저장 / 취소**합니다. **레벨업 보너스** 전체 목록은 별도 탭입니다. 개별 유닛 해금 조건은 현재 데이터에 없어 만들지 않았으며, 덱 해금 수정은 덱 전체에 적용됩니다.
2. **출석**에서 일차별 셀의 **＋ 보상 추가**를 누릅니다. **우리 아이템**의 아이콘을 클릭하거나 드래그해 넣고 수량을 입력합니다. 아이템 목록은 필요할 때 열고 닫습니다. 보상은 해당 출석 행에 직접 저장됩니다.
3. **Excel 내보내기**는 강화 5개 시트 또는 출석 2개 시트를 한 파일로 저장합니다. 출석 보상 여러 개는 Rewards 셀에 `Gold:500;Stamina:10`처럼 저장합니다. `.data.json` 파싱 결과와 `.schema.json` 타입 규약도 함께 생성합니다.
4. 변경은 사용자 작업 폴더의 `content-project-v2.json`에 자동 저장됩니다. **프로젝트 저장**으로 전달용 JSON을 보관하고 **불러오기**로 다른 PC에서도 엽니다.
5. **Excel 가져오기** 또는 **자료 목록 → 가져와 편집**으로 해당 파일을 다시 엽니다. 내보낸 Excel은 자료 목록에서도 표시됩니다. Excel에 포함된 표만 교체하고 나머지 표는 유지합니다. **전체 자료 · 검사**에서 개별 표와 전체 ZIP도 내보낼 수 있습니다.
6. **밸런스 편집**으로 돌아가면 기존 화면과 작업 중 수치가 유지됩니다.

**자료 목록 → 동봉 자료 사용 → 새로고침**에서 현재 프로젝트 구조의 Excel을 바로 선택할 수 있습니다. `UnitBalance.xlsx`(유닛 정보·비용), `UnitLevelBonus.xlsx`(레벨업 보너스), `PermanentUpgrade.xlsx`(영구강화), `Attendance.xlsx`(출석), `Party.xlsx`, `AccountSettings.xlsx`, `Profile.xlsx`, `Tutorial.xlsx`를 동봉합니다. `가져와 편집`을 누르면 해당 편집 화면이 열립니다. 동봉 자료는 프로젝트 에셋의 스냅샷이며 개인 편집값을 자동으로 덮어쓰지 않습니다.

기존 **저장한 실험 / 실험 전달하기**는 무한모드·계정 성장용입니다. 자료 목록은 기존 양식과 새 강화·보상·출석 Excel을 모두 지원합니다. 콘텐츠 전체 프로젝트는 JSON으로도 전달합니다. 기존 계정 성장 Excel과 콘텐츠의 계정 수치 스냅샷은 자동 동기화되지 않습니다.

## 포함 범위

현재 기능의 14개 표 + 자동 전개하는 ResearchLevel 표만 관리합니다. Item은 아이콘 선택을 위한 공통 참조 데이터입니다.

- 영구강화: 노드·수치·선행 조건 / 트리 기본 설정 (3종·61개 노드)
- 유닛강화: 유닛·족장 기본 수치 / 레벨별 비용·성장 / 레벨 보너스 설명
- 출석: 일차별 보상 / 출석 주기·초기화
- 아이템 목록: 출석 보상 셀에서 여는 공통 선택창
- 파티·덱: 유닛 명단·족장·기본 해금
- 재화·스태미나: 초기값·회복·최대치·출격 비용
- 계정 성장: 레벨별 필요 경험치 / 승리·패배 경험치
- 프로필 / 튜토리얼

우편·한정 상점 시간·알림과 가챠·이벤트·인앱상품·유물 등의 기획은 메뉴와 Excel에서 제외합니다. 영구강화 비용·튜토리얼 완료 보상·전투 추가 재화 같은 미구현 입력칸도 표시하지 않습니다. 이전 JSON 데이터는 호환성을 위해 보존합니다.

실제 프로젝트 에셋과 임시 구현에서 읽은 값의 출처를 표시합니다. 게임 아이콘 32개를 포함하며 네트워크 없이 실행합니다.

서버용 Excel과 파싱 JSON에는 Source·Note·SO 경로·이전 저장 이름·참고 성장률을 제외합니다. 편집 프로젝트 JSON에는 원본 추적 정보를 보존합니다. 파티의 족장은 ChiefAsset 경로 대신 ChiefId 키를 사용합니다. 동봉 자료 갱신은 생성본의 내용 해시가 일치하는 파일에만 적용하며, 직접 수정한 파일이 있으면 보존하고 별도 `-server.xlsx`를 제공합니다.

## 적용 범위

Excel/파싱 결과 규약은 **v3**입니다. 강화는 `EnhancementBalance.xlsx`, 출석은 `Attendance.xlsx`입니다. 레벨업 보너스는 UnitId + Level 키와 Description / EffectStatus / EffectId / EffectParams로 구분합니다. 기존 설명은 DescriptionOnly로 유지하며 효과를 추측하지 않습니다. [파싱 규약](EXCEL-CONTRACT.md)에 열·타입·JSON 형식을 정리했습니다. 프로젝트 복원 JSON은 v2 형식을 호환 유지합니다. 전체 ZIP은 15개 표와 manifest를 포함합니다.

기존 Unity 강화 Importer는 별도 `Account_영구강화` 규약이고 구조·비용을 가져오지 않습니다. 현재 실제 에셋의 0.2% 같은 소수 퍼센트도 기존 Importer의 정수 % 제한과 맞지 않습니다. 새 콘텐츠를 게임/뒤끝에 반영하는 Importer·서버 지급 로직 연결은 별도 개발이 필요합니다. 이 프로그램은 실제 유저 데이터나 서버에 쓰지 않습니다.

검사는 중복 키, 필수값, 수량·범위, 참조, 트리 순환·겹침, 출석 일차를 포함합니다. 오류가 있으면 Excel 추출을 막으며 미완성 초안은 JSON으로 저장할 수 있습니다.

## 개발·검증

- `app/`: 기존 `schema.cjs`, `store.cjs`, `workbook.cjs`를 유지합니다. `library.cjs`, `ui/renderer.js`에는 콘텐츠 자료 가져오기만 추가했습니다.
- `content-workbook.cjs`: 여러 시트 Excel 작성·양식 검사·타입 복원·참조 검증.
- `ui/content/reward-grid.js`: 아이콘 드래그·한 셀 여러 보상·일차별 편집.
- `ui/content/tutorial-rich.js`: 튜토리얼 안내 문구의 리치 텍스트 편집·미리보기. 굵게·기울임·밑줄·색상·크기 버튼과 태그 원문 편집을 지원합니다. Excel에는 태그·줄바꿈을 그대로 보존합니다. 미지원 태그는 텍스트로 표시합니다.
- `integrate.py`: 인접 `reward-editor`의 데이터 편집 모듈을 가져와 기존 작업실에 맞게 연결합니다. 새 `content/desktop.js`, `planner-theme.css`는 보존합니다.
- `package.py`: 프로젝트 내부 `GGD-Planner/` 런타임으로 재패키징합니다. 새 환경에서 최초 런타임을 복사하려면 `--runtime <기존 배포 폴더>`를 지정합니다.
- `install.py --target <외부 설치 폴더>`: 필요한 경우에만 다른 설치본을 업데이트합니다. 프로젝트 폴더에서 직접 실행할 때는 필요 없습니다.
- `check-content.cjs`: 데이터 참조·잘못된 수량·트리 순환·초안·15개 XLSX·제외 항목 검증.
- `check-workbook.cjs`: 강화·직접 출석 보상·구조화 보너스 Excel 왕복·이전 파일 이관·잘못된 수량/참조/효과 JSON 거부 검증.
- `check-excel-contract.cjs`: 모든 작성용 열 규약, 출석·미션·강화 비용의 공통 셀 형식, 이전 공격 속도 열 호환, 작성용과 뒤끝 전송 데이터 일치 검증.
- `check-ui.cjs`: 실제 Electron에서 탭·드래그 이벤트·보상 셀·Excel 왕복·자료 목록 가져오기 검증. 임시 사용자 폴더를 사용합니다.
- 기존 내장 `--smoke=결과경로 --workspace=임시폴더`: 기존 기능 29개 회귀 검사.
- `--content-smoke=결과경로 --workspace=임시폴더`: 디버거 연결 없이 실제 Electron 콘텐츠·저장·추출 검사와 화면 캡처. 동일 임시 폴더로 다시 실행하면 재시작 복구도 검사합니다.

```powershell
python Tools/planner-studio/package.py
node Tools/planner-studio/check-content.cjs
node Tools/planner-studio/check-workbook.cjs
node Tools/planner-studio/check-ui.cjs
```

실행 파일 사용에는 Node/Python/Unity/Excel이 필요 없습니다.

`integrate.py`는 이전 `reward-editor` 소스에서 초기 확장을 재구성하는 보조 스크립트입니다. 현재 Git 소스로 일반 빌드할 때는 실행하지 않습니다. `app/README.md`는 추출 전 기본 편집기의 참고 문서이며 현재 설치·패키징 절차는 이 문서를 따릅니다.
