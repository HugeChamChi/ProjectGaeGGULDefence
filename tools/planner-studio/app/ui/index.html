뒤끝 DEV 적용

1. 적용할 자료를 선택하고 파일을 준비합니다. 2. 공식 콘솔에서 표시된 DEV 차트에 업로드·적용합니다. 3. 개발 빌드에서 설정 로드와 동작을 확인합니다.

유닛 기본 스탯은 공격력·공격 속도·쿨타임·식량·드론 수를 연결합니다. 강화 비용·레벨 보너스 실행·유저 레벨 저장은 포함하지 않습니다. 미션 보상 지급과 진행 저장도 아직 미연결입니다. 편집 중인 내용은 먼저 수정 저장하세요.

OFF에서는 시작시간·수치 등이 각각의 열로 표시됩니다. 일반 표 형식은 최신 게임 클라이언트가 필요합니다. 이전에 준비한 파일은 새 형식으로 다시 준비하세요.

유닛은 기본 스탯만, 미션은 설정만 적용합니다. 강화 구매·출석·미션 저장 및 보상 지급은 아직 운영 연결 전입니다.

아직 파일을 준비하지 않았습니다.

작성·검토용 엑셀과 열 규약을 같은 폴더에 함께 저장합니다. 기획 수정은 작성용 엑셀에서 하고 다시 준비하세요. 업로드 파일(.backend.xlsx)은 동일 데이터에서 자동 생성하므로 직접 수정하지 않습니다.

공식 콘솔에서 위 차트를 생성 또는 선택하고 이 파일을 업로드한 뒤 「차트 파일 적용」을 누르세요. 파일 준비나 콘솔 열기는 업로드 완료를 뜻하지 않습니다. 게임의 원격 설정을 켜고 게임 앱 또는 Play를 다시 시작해야 적용됩니다.

게임 담당자는 Unity Editor/Pipeline·뒤끝 로그인·Unity CLI가 준비된 PC에서 프로젝트를 선택하고 서버 적용 파일을 대조할 수 있습니다. 파일 일치 확인과 게임 플레이 검증은 별도입니다.
