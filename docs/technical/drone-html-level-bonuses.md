## 저작·업로드

- 기획툴 `보너스 능력`에서 대상, 해금 레벨, 효과 순번, 스탯, 단위, 수치를 설정한다. 효과 클래스는 `StatModifierBonus` 또는 베탕 주기용 `EveryNthCycleBonus`이다. 문자열로 임의 클래스를 실행하지 않고 Enum과 허용된 스탯 매핑으로 연결한다.
- `Percent=20`은 20%다. `PercentagePoints=10`은 치명타 확률 등에 직접 더하는 10%이며 화면에는 `%`만 표시한다.
- 등급별 추가 생산/소모는 각 등급 스탯으로 4행을 쓴다. 지속 효과는 비율과 지속시간을 별도 행으로 쓴다. `ChiefStartsReady`는 고정 수치 0/1, `FoodFifthMultiplier`는 고정 수치 2 또는 2.5다.
- `보너스 설명`은 문구·숫자 강조·용어 링크를 관리한다. 문구를 바꿔도 전투 수치는 바뀌지 않는다. 알팡 공격속도 툴팁 수치는 효과 행에서 읽는다.
- 유닛 요약/기존 UnitMilestone은 위 두 표에서 생성한다. 기존 기본값은 최초 1회 최신안으로 이동하며, 사용자가 바꾼 값은 유지한다. 이후 의도적으로 이전과 같은 값을 입력해도 덮어쓰지 않는다.
- 작성용 `UnitBalance.xlsx`에는 기본 4개 표와 BonusEffect/BonusDescription, 총 6개 시트가 포함된다.
- **뒤끝 업로드는 `DEV_UnitLevelBonuses` 차트에 `UnitLevelBonuses_2026-10-30.xlsx` 하나만 등록·적용한다.** 단일 시트이며 Part 39행 + Description 30행, 헤더 제외 69행이다. Base64/Payload/ReleaseKey 열이 없다. 작성용 다중 시트 파일은 업로드하지 않는다.
- 이번 변경에서 UnitBaseStats/MissionEvents/ResearchBalance는 다시 업로드할 필요가 없다. LIVE 배포는 별도 작업이다.

## 실행 규칙

- 델탕 공유 용량 +10은 여러 델탕을 배치해도 가장 큰 값 한 번만 적용한다. 배치 제거 시 진행 중 소비 예약을 무효화하지 않고 남은 가용 스택만 상한으로 자른다. 이미 발사한 예약만 새 상한을 넘는 동안은 추가 생산을 받지 않고, 취소 환불도 새 상한까지만 돌려준다. 선택지 충전 감소 후 레벨 보너스의 고정 -1을 적용한다.
- 감망 +20%는 기본 계수가 아닌 스택 계수 부분에만 곱한다. 선택지의 스택 피해 보정과 곱한다.
- 디시그망은 회복 후 강화 사격 1개를 저장한다. 재회복은 중첩하지 않는다. 정규 일반공격 시작 시 소비하며 추가 공격은 소비/충전 이벤트를 발생시키지 않는다. 투사체·연발의 비동기 적중에도 원래 사격 배율을 전달하고 스킬 피해에는 적용하지 않는다. 보스 변경/사망은 다음 보스로 강화 사격을 넘기지 않는다.
- 젤탕의 속도 보너스는 자체 생산 시계만 빠르게 한다. 군단 식량에는 적용하지 않는다. 보스 보상은 현재 자체 초당 생산량의 5배이며 5번째 생산 카운터를 늘리지 않는다. 15레벨 배율은 12레벨 배율과 중첩하지 않는다.
- 알팡 공격력은 유닛의 공격력에만 적용하며 족장 고정 집결 피해·식량은 제외한다. 공속 버프는 재발동 시 시간만 갱신한다. 받는 피해 증가는 실제 집결 피해 적중 뒤 적용한다. 기존 받는 피해·방어력 감소 디버프와 공존하며 별도 그룹의 받는 피해 배율은 곱한다.
- 런 레벨은 계정 UnitLevels를 복사한 UnitLevelSnapshot에서 읽는다. 로비 시안의 레벨을 실제 계정에 저장하는 구매 흐름은 이 작업에 포함하지 않는다.
