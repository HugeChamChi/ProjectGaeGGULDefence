## 의존성

- UnitData.LevelBonuses → UnitLevelBonusDefinition → StatModifierBonus / EveryNthCycleBonus: 저작 데이터.
- UnitLevelSnapshot: 계정 경계에서 복사한 레벨. UI·PlayerPrefs·뒤끝 SDK를 참조하지 않는다.
- UnitFactory.Init(snapshot) → UnitDependencies → UnitBase.Init → UnitLevelBonusController: 런 레벨 전달과 유닛별 상태 생성.
- UnitStatsModifier: 공격력·일반공격 빈도·치명 피해 값을 읽어 기존 계산에 합친다.
- Drone_Betan: 기본 충전 완료 시 공통 주기를 1회 진행하고 피해 보정을 발사 요청에 보관한다.
- DroneUnit: UnitData의 전투 드론 계수로 계산한다. 베탕 이외의 기본값은 1이다.
- 효과 부품은 유닛·UI·서버·선택지 관리자를 호출하지 않는다. 이벤트 구독이나 전역 레벨 상태를 추가하지 않는다.

## 정확한 적용 규칙

- 6·12 보너스는 같은 basic_skill 순번을 사용한다. 기본 충전시간은 6 / 4.2 / 6 / 4.2초, 피해 배율은 1 / 1.4 / 1 / 1.4다.
- 순번은 기본 충전 완료/스킬 발동에 확정된다. 이후 모션이 취소되면 해당 회차는 소비되며 소급 환급하지 않는다.
- 선택지 주기/함대 자폭은 기본 순번을 소비하거나 6·12 보정을 받지 않는다. 공격력·치명 피해 보너스는 추가 자폭에도 적용한다.
- 피해 배율은 예약/보류 요청에 캡처한다. 폭발 순서나 다음 주기의 시작으로 바뀌지 않는다. 피해/치명/반올림은 기존 공용 계산을 사용한다.
- 일반공격 공속 보너스는 기본 자폭·선택지 타이머·생산 속도와 독립이다.
- 공격력 보너스는 기존 인게임 강화 배율과 곱하고, 동일 레벨 능력치 부품끼리는 가산한다. 치명 피해는 기존 배율에 +0.5를 더한다.
- 레벨 값과 해금된 부품 값은 초기화 때 복사한다. 임시 전투 등급 변경은 계정 레벨을 변경하지 않는다. 이동은 순번을 유지하며 새 유닛 초기화는 1회차부터 시작한다.
- 수리 키트는 기존 DroneManager.NotifySelfDestructExplosion 경로를 사용하고 완충에서 제한한다. 초과 회복은 다음 주기로 넘기지 않는다.

## 현재 적용 경계

기본 수치와 선택지는 게임 에셋에 반영됐다. 레벨 보너스는 런타임 실행까지 연결되어 명시적으로 주입한 레벨에서 동작한다.
실계정 유닛 강화 레벨 저장/구매 경로는 아직 없으므로 기존 UnitFactory.Init()는 레벨 1을 사용한다. 미리보기 DeckUpgradeProgress를 실제 계정 레벨로 읽지 않는다.
향후 계정 로더가 검증한 UnitData 이름 키→레벨 값을 UnitLevelSnapshot으로 전달하면 된다. 계정 변경은 새로운 전투 스냅샷으로 처리한다.
현재 기획툴 자유 EffectId/EffectParams 및 UnitBaseStats 차트는 이 부품 정의의 전송 규약이 아니다. 새 부품 차트 직렬화·지원 버전 검증은 별도 연결 대상이다.
이전 outputs/backend-upload-20261029의 유닛 Excel은 이 확정 밸런스 적용 전에 생성했다. 최신 배포용으로 재사용하지 말고 갱신한 기획 원본에서 다시 생성해야 한다.

## 밸런스 확인

일반 DPS = 공격력 ×0.3 ×드론 수 ×빈도, 자폭 DPS = 공격력 ×자폭 계수 ÷6.
치명·편차·방어·반올림·모션·비행·선택지를 제외하면 일반 비중은 약 39.8 / 39.8 / 39.8 / 39.8%다.
