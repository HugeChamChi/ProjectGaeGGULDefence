## 갱신 방법

- 착수 시 해당 행의 상태를 갱신하고 작업 소유권은 `active.md` 작업판에 기록한다.
- 수정은 끝났고 Play·실기기 확인만 남은 일은 원래 표에서 빼서 "검증·복구 대기" 표로 옮기고, 무엇을 확인하면 끝나는지 적는다. 처음부터 할 일처럼 보이게 남겨 두지 않는다.
- 사용자가 지금 하지 않기로 정한 일은 행 제목 뒤에 `보류(MM-DD)`를 적는다. Dreaming 기계 점검은 보류 행을 오래된 항목으로 올리지 않는다.
- 끝난 일은 결과 링크를 짧은 인계에 남기고 이 목록에서 제거한다. 상세 설계/검증 로그는 해당 원본/RESULT에서 유지한다.
- 오래된 기록에서 가져온 후보는 최신 완료 기록과 대조한다. 제안은 사용자 결정 없이 승인된 구현 작업으로 바꾸지 않는다.
- 보류된 장기 방향은 [라이브 서비스 후속 제안](technical/live-service-refactor-plan.md)에서 보존한다. 이 목록을 과거 기록 전체의 복사본으로 늘리지 않는다.
