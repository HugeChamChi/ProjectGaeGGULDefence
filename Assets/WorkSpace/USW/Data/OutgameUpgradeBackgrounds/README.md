# 최종 강화 화면

`Assets/WorkSpace/USW/Data/OutgameUpgrade.unity`를 사용합니다.

추천 표시는 1번 골드 팝, 하단 정보 영역은 1번 겹침형으로 확정했습니다. 비교 씬과 선택 버튼, 나머지 디자인 시안은 제거했습니다.

노랑·주황 이름 띠에 아이콘 카드가 겹칩니다. 아이콘 카드는 강화 트리와 같은 상태별 프레임을 사용합니다. 하단 추천 강화는 노랑·주황 바탕, 강화 버튼은 청록입니다. 비용 숫자는 큰 볼드이며 부족하면 분홍색입니다. 골드 아이콘 중심은 비용 칸의 왼쪽 끝에 맞추고, 강화 성공 시 아이콘과 누른 버튼에 탄력 있는 확대·축소 효과를 적용합니다.

흰색 톱니바퀴·상승 화살표가 흔들리며 올라가는 연구실 배경은 MAX 완료 단계까지만 표시됩니다.
