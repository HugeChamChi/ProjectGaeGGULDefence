# 최종 강화 화면

로비 `Assets/Scenes/LobbyScene.unity`의 **강화** 탭에서 트리와 정보 패널을 바로 표시합니다. `Assets/WorkSpace/USW/Data/OutgameUpgrade.unity`는 단독 확인용이며, 두 화면 모두 `OutgameUpgrade/UpgradeViewSettings.asset`을 사용합니다. 이 폴더의 `Background_02_CyanDiagonal.asset`은 이전 배경 설정 기록이며 현재 씬에서 참조하지 않습니다.

하단은 `design/1080_x_1921.png` 기준 KHJ 원본 카드/아이콘 프레임/노란 추천 버튼/파란 강화 버튼을 사용합니다. 좌우 스와이프, 추천 따라가기 토글, 페이지 점을 없애고 추천 강화와 선택 강화 두 버튼으로 고정했습니다.

제목 띠는 노랑·주황, 정보판은 남색, 하단 아이콘은 금색 프레임입니다. 선택 MAX도 파란 버튼에 표시하며 옆의 추천 버튼을 유지합니다. 사용자 지정 `KCC-Ganpan`을 흰 글자·검은 외곽선으로 사용하고, 수치는 시안대로 노란색으로 강조합니다. 커스텀은 강화 전용 `UpgradeFont_WhiteBlack.mat`에만 저장하며 공용 폰트는 수정하지 않습니다.

수치는 다음 레벨 효과 하나만 `0.2%`로 표시합니다(MAX는 현재 최종 효과). 카드 위 투명한 잎 영역 80만큼 트리를 뒤로 겹쳐서 검은 띠가 노란 제목 위에 보이지 않게 했고, 버튼 하단 여백도 줄였습니다.

2026-10-17: 기존 그림 배경을 빼고, MAX 완료 단계까지 차오르는 색 배경 안에 기존 `HSD/Sprites/UnitData Icon.png`의 검은 개구리 한 마리 얼굴이 대각선으로 흐르도록 변경했습니다. 겹친 두 마리 아이콘은 사용하지 않습니다. 원본 비트맵은 수정하지 않고 importer를 Single Sprite로 바꿨습니다. 현재 강화는 무료이며 별도 비용 칸은 표시하지 않습니다.
