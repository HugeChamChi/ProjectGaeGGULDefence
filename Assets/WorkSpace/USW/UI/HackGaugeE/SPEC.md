# 해킹 스택 게이지 (E. 사선 스트립) — 구현 스펙

보스 HP바 바로 아래에 붙는 사선 눈금 게이지. 최대 50스택, 눈금 25칸(스택 2개당 1칸).

## 좌표계
- 모든 수치는 **@1x 기준(화면 폭 407px)**. PNG는 전부 **@3x**로 렌더됨 (1x 수치 × 3 = PNG 픽셀).
- 원점은 각 요소의 왼쪽 위.

## 화면 배치 (407×743 기준)
| 요소 | x | y | w | h |
|---|---|---|---|---|
| 스트립 전체 | 66 | 68 | 314 | 18 |
| 숫자 라벨 `46/50` | 오른쪽 정렬, 화면 오른쪽에서 30px | 88 | auto | 12 |

- 스트립은 HP바 바로 아래(간격 약 4px), HP바 오른쪽 끝(≈ x 378)과 맞춤.
- 해상도가 다르면 HP바 RectTransform 기준으로 앵커링 (HP바 하단 + 4px, 오른쪽 끝 정렬).

## 스트립 내부 구조 (스트립 로컬 좌표, @1x)
| 레이어 | 파일 | x | y | w | h |
|---|---|---|---|---|---|
| 1. 배경 | `pieces/strip_bg.png` | 0 | 0 | 314 | 18 |
| 2. 태그 | `pieces/tag_hack.png` / `tag_ready.png` | 0 | 0 | 64 | 18 |
| 3. 눈금 ×25 | `pieces/tick_on/half/off.png` | 아래 참고 | 4 | 7.44 | 10 |

- 눈금 영역: x 70 ~ 304 (폭 234), 눈금 폭 7.44, 간격 2, 피치 9.44.
- i번째 눈금(0부터) **중심** x = `70 + i * 9.44 + 3.72`, 중심 y = `9`.
- 눈금 PNG에는 사선 기울기와 발광 때문에 좌우 6px, 상하 4px 여백(@1x)이 포함돼 있음 → **피벗을 중심(0.5, 0.5)으로 두고 중심 좌표에 배치**. PNG 원본 크기 그대로(@3x → 1/3 스케일) 사용.
- 태그 텍스트를 엔진 폰트로 쓰고 싶으면 `tag_blank.png` + 텍스트(Chakra Petch Bold 10px, 자간 1.5px, 색 #0D1024, 왼쪽 패딩 8px, 세로 중앙).

## 상태 로직
```
stack = clamp(stack, 0, 50)
full  = floor(stack / 2)          // 꽉 찬 눈금 수
for i in 0..24:
    if i < full:                         tick_on
    elif i == full and stack % 2 == 1:   tick_half   // 홀수 스택일 때 반칸
    else:                                tick_off
tag   = stack >= 50 ? tag_ready : tag_hack
label = "{stack}/50"
```

## 숫자 라벨
- 폰트: Chakra Petch Bold (`ChakraPetch-Bold.ttf`, OFL 라이선스), 12px, 자간 0.5px
- 현재값 `#FFFFFF`, `/50`은 `#C9CDF0`
- 외곽선 1.5px `#0D1024` (TMP Outline 또는 4방향 그림자)

## 색상
| 용도 | 색 |
|---|---|
| 강조(태그·켜진 눈금) | `#5CE1FF` |

| 꺼진 눈금 | `#2A2F55` |

| 켜진 눈금 발광 | `#5CE1FF` 블러 3px (PNG에 포함됨) |
