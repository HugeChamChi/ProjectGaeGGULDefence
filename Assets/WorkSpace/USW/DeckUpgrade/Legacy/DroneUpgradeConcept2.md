# 드론 덱 강화 · 네이비 시안

`DroneUpgradeConcept2.unity`만 유지합니다. 씬을 열고 Play하면 로그인 없이 실행됩니다.

- 드론 덱 탭은 족장 알팡입니다. 메인 화면 상단의 큰 유닛 전시는 제거했습니다.
- 펼치면 맨 위 중앙 원형 알팡 강화 슬롯, 아래에 드론 5종 카드가 나옵니다.
- 높이 300인 탭에는 ‘드론’만 크게 표시합니다. 중앙 알팡 양옆에 실제 전투 드론 프리팹의 동그란 드론 스프라이트 두 개씩 비행합니다. 빔은 제거했습니다.
- 탭의 알팡은 240 크기로 확대하고 접힌 상태에서는 뒤 원 오브젝트를 숨깁니다. 펼침 0.42초/접힘 0.20초입니다.
- 슬롯은 넓은 간격의 3열이며 한 번 확대 후 정착합니다. 다른 덱 탭은 삭제하고 드론만 유지합니다. 골드 게이지는 아이콘/화살표까지 포함한 폭을 기준으로 중앙 정렬합니다.
- 알팡은 레벨당 전체 유닛 능력치 +2%, 개별 유닛 강화는 +10%입니다. 두 효과는 곱해서 적용하는 시안입니다.
- 알팡은 별도 레벨/비용을 쓰고 같은 보유 돈을 소비합니다. 원본 UnitData, 실계정, 인게임 전투는 변경하지 않습니다.
- 정보창: 상단 유닛 → 이름 → 현재/강화 후 초록 수치 → 골드 게이지 → 특수능력 세로 스크롤 → 강화 버튼.
- 공격속도는 원본 공격 간격을 초당 공격 횟수로 환산합니다.
- 강화할 때 창은 고정하고 버튼만 바운스합니다. 유닛은 공격 후 idle 복귀, 생산형은 원본 skill을 사용하고 알팡은 idle을 유지합니다. Spine 없는 디시그망은 이미지입니다.
- 정보창 유닛 뒤 큰 원 대신 작은 빛 알갱이가 천천히 올라갑니다.
- 골드 아이콘은 게이지 왼쪽 끝에 걸쳐 표시합니다. 게이지 반사/발광은 제거하고 화살표의 바운스와 심머만 유지합니다.
- 기존 ResearchInfoPanel의 짙은 청록 패널/카드 색상을 정보창에 반영하고, 메인은 어두운 차콜과 채도를 낮춘 황갈색 카드로 구성합니다. 노랑·주황은 버튼/강조에 사용합니다.
- 특수능력은 스킬/레벨 보너스 두 탭입니다. 3·6·9·12·15레벨 보너스는 공격력 10% 증가 표시용 예시이며, 미해금 행은 검은 반투명 덮개와 자물쇠를 표시합니다. 해금 시 둘 다 사라집니다. 추가 보너스 전투 계산은 연결하지 않은 UI 시안입니다.
- 성공률 문구와 레벨 보너스 설명 아래 작은 해금 상태 문구는 표시하지 않습니다.
- 스킬명은 황갈색 전용 칸으로 본문과 구분합니다. 탭/강화 슬롯 알팡도 실제 Spine idle을 재생하며 알팡 강화 시에도 idle을 유지합니다.
- 알팡의 스킬 칸은 실제 족장 집결 사격이며 피해/대기시간은 `chief.AlphanSkill`에서 읽습니다. 전체 강화 설명으로 대체하지 않습니다.
- 하단 안내, ‘돈으로 강화’, 강화 성공 안내 문구는 삭제했습니다.
- 펼친 족장과 원은 320 크기이며 구분선은 원 중심보다 50 아래입니다. 골드 아이콘/화살표는 15% 확대하고 각각 왼쪽/오른쪽으로 7/8만큼 벌립니다.
- 초기 돈 12,000, Lv.1, 비용 현재 레벨 ×150, 최대 Lv.20. PlayerPrefs `DeckUpgradePreview.v1`에 독립 저장합니다.

`AlphanPreview*`는 기존 알팡 텍스처/바이너리를 참조하는 UI 미리보기용 Spine 에셋입니다.
생성/검증: `Tools/verification/DeckUpgradeConceptAuthoring.cs`의 Build, `DeckUpgradeConceptChecks.cs`의 Check/Export.
실행 캡처: `outputs/drone-concepts/index.html`.
